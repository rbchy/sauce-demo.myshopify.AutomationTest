# Sauce Demo – BDD Cucumber Automation Framework

A lightweight automation framework for the Sauce Demo website using Java, Selenium WebDriver, Cucumber (Gherkin), TestNG, Maven, and Eclipse. The project demonstrates clean structure, maintainable design, and practical UI automation for core e‑commerce flows.

---

## Tools & Technologies
Java • Selenium WebDriver • Cucumber (BDD) • TestNG • Maven • Eclipse

---

## Project Structure
features/ • steps/ • hooks/ • runner/ • pom.xml • testng.xml

---

## Test Coverage
Covers authentication, product interactions, cart behavior, UI validation, navigation flows, and search functionality.

---

## Running Tests
- Maven: `mvn clean test`  
- TestNG Suite: `mvn test -DsuiteXmlFile=testng.xml`  
- Eclipse: Run the TestNG runner class

---

## Summary
A clean, maintainable BDD automation framework showcasing real-world UI testing practices and modern QA engineering skills.
